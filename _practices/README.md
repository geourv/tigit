# Materials de treball no publicats

Aquest directori conserva demostracions, dades, projectes editables i captures que serveixen per preparar les activitats del manual. Està exclòs de la construcció de Jekyll: els fitxers estan versionats al repositori, però no es copien al web publicat.

No és un espai secret. Qualsevol persona amb accés al repositori públic de GitHub pot consultar-ne el contingut.

## Convenció general

- El directori del projecte descriu la finalitat estable, no el territori ni l'any de les dades.
- Els fitxers editables utilitzen un sufix de dos dígits que identifica el capítol que n'ha produït l'estat acumulatiu.
- El territori i el període s'inclouen als resultats exportats, que han de poder interpretar-se fora del projecte.
- L'any indica el període de referència de les dades, no l'any d'edició del fitxer.
- Els originals es conserven sense modificar i mantenen el nom rebut de la font.

El projecte pràctic acumulatiu es troba a `tigit-projecte-territorial/`.
