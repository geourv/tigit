# Projectes QGIS

Els projectes QGIS conservaran una fita per fase:

- `tigit-04-dades-espacials.qgz`;
- `tigit-05-integracio-sig.qgz`;
- `tigit-06-llenguatge-cartografic.qgz`;
- `tigit-08-cartografia-tematica.qgz`.

Cada fitxer continuarà l'anterior mitjançant `Anomena i desa`, però no el substituirà. Les rutes seran relatives a l'arrel del projecte pràctic.

Els prefixos són identificadors tècnics estables. La fase de color es completa abans d'obrir aquests projectes, i `tigit-05-integracio-sig.qgz` rep la taula `map_export` derivada del llibre cromàtic encara que els números dels fitxers no expressin aquest ordre pedagògic.
